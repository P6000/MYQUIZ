Introduction: This assignment involves developing a native Android application designed to facilitate effective studying through the use of flashcards. The primary goal is to create an engaging and interactive quiz app that tests users’ knowledge of history, providing immediate feedback and tracking performance to enhance learning outcomes. By leveraging Kotlin and Android Studio, students will gain practical experience in app development, user interface design, and version control using GitHub.
Background: Flashcards are widely recognized as a powerful learning tool due to their simplicity and effectiveness in reinforcing memory. Typically used in various educational contexts, flashcards enable learners to self-assess their understanding of key concepts across different subjects. In this project, the flashcard app serves as a digital platform for users to answer history questions, receive instant feedback, and review their performance.
Objectives: The core objective is to develop a fully functional, user-friendly Android app that presents users with a series of history questions in a quiz format. The app will feature a clean interface comprising three main screens: a welcome screen, a flashcard question screen, and a score screen. Users will answer questions with "True" or "False" options, and the app will provide immediate feedback on each response. After completing five questions, the app will display the total score and offer options to review the flashcards or exit the application.

Key Features and Requirements:
User Interface (UI):

Welcome Screen:
Presents a brief description of the app’s purpose.
Displays a welcoming message.
Includes a "Start" button to initiate the quiz.

Flashcard Question Screen:
Shows a single question at a time.
Provides two answer buttons labeled "True" and "False".
Contains a "Next" button to proceed to the subsequent question.
Displays feedback ("Correct!" or "Incorrect") immediately after each answer.

Score Screen:
Displays the total number of correct answers out of five.
Offers personalized feedback based on the user's performance.
Includes a "Review" button to revisit all flashcards with correct answers.
Contains an "Exit" button to close the app.

Development Requirements:
Use Kotlin programming language within Android Studio.
Implement five history questions for the quiz.
Incorporate version control by integrating GitHub repositories and automate builds and testing with GitHub Actions.
Comment the code thoroughly to enhance readability and maintainability.
In summary, this assignment challenges students to create an interactive, educational Android app that combines UI design, core programming concepts, and version control practices. The final product aims to provide users with an engaging way to learn history through a structured flashcard quiz format.
